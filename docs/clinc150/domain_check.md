# Did CLINC150's teacher suffer from a banking prompt?

_Generated by `scripts/domain_check.py`. Every CLINC150 label was made with a prompt whose first line describes a banking app's support inbox and whose format examples are Banking77 intent names. Here the same test queries are relabelled with CLINC150's own line and examples: same batches, same settings (gpt-oss-120b, top-3, reasoning low). Accuracy vs gold._

| teacher prompt | accuracy on 200 test queries |
|---|---:|
| banking line (the published labels) | 0.890 |
| CLINC150's own line | 0.875 |
| own − banking | **-1.5 pt** (95 % -4.5 to +1.5) |

The two prompts give the same answer on 95.5% of queries; the own line is right where the banking one is wrong on 3, and the reverse on 6. **The banking line made no measurable difference**, so the published CLINC150 numbers stand; new labels use the dataset's own line.
